Тексты в чате

Плагин дает ChatGPT и Codex инструкции для обработки текста в текущем чате. У плагина нет отдельного сервера, аккаунта, базы текстов или аналитики. Он не отправляет тексты издателю. Если в среде доступен встроенный Python-сканер, он проверяет текст в этой среде.

Как OpenAI обрабатывает и хранит сообщения, описано в политике OpenAI. Управление историей, экспорт и удаление описаны в справке по настройкам данных ChatGPT.

Сайт и обращения в поддержку

Сайт размещен на GitHub Pages. Он не содержит форм или счетчиков. GitHub регистрирует IP-адреса посетителей для безопасности. Как GitHub хранит эти сведения и какие настройки доступны, описано в политике GitHub.

При обращении в GitHub Issues имя аккаунта и содержание сообщения видят сопровождающие проекта и другие посетители репозитория. Сопровождающие используют обращение, чтобы ответить или воспроизвести проблему. Закрытое обращение может оставаться публичным. Свой текст можно отредактировать через GitHub. Если нужно удалить сведения из обращения, связывайся с сопровождающими через страницу поддержки, не дублируя сами сведения.
